# Real-Time-Messaging-System
A real-time chat application backend built with FastAPI, WebSockets, and SQLAlchemy. Users can register, login, send messages, and chat in real-time with message history and active user tracking.

---
## How It Works


```
User connects via WebSocket
        ↓
Server authenticates user from DB
        ↓
Last 50 messages loaded from DB and sent to user
        ↓
User sends a message
        ↓
Message saved to DB
        ↓
Message broadcast to all connected users
        ↓
User disconnects → last_seen updated → broadcast leave message
```

## Database Models

### User
| Column | Type | Description |
|---|---|---|
| id | Integer | Primary key |
| username | String | Unique, required |
| password | String | Plain text (no hashing yet) |
| last_seen | DateTime | Updated on login, message send, connect/disconnect |

### Message
| Column | Type | Description |
|---|---|---|
| id | Integer | Primary key |
| content | String | Message text |
| time_send | DateTime | Timestamp |
| user_id | Integer | Foreign key → User |

## REST API Endpoints

### Auth
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/auth/register` | Register a new user |
| `POST` | `/auth/login` | Login with username and password |

### Users
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/users/{user_id}` | Get user profile |
| `PUT` | `/users/me/username` | Update username |
| `GET` | `/all-users` | List all users |
| `GET` | `/users/active` | List users active in last 5 minutes |

### Messages
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/message/{user_id}` | Send a message as a user |
| `GET` | `/messages/{user_id}` | Get all messages by a user |
| `GET` | `/messages` | Get all messages from all users |

## WebSocket

### Connect
```
ws://localhost:8000/ws/{client_id}
```

On connect:
- User is authenticated from DB
- `last_seen` is updated
- Last 50 messages are sent as history
- Join message is broadcast to all

### Message format sent by client
```json
"Hello everyone!"
```

### Message format received by client
```json
{
  "isMe": true,
  "data": "Hello everyone!",
  "username": "yordan"
}
```

`isMe` lets the frontend style your own messages differently.

### On disconnect
```json
{
  "isMe": false,
  "data": "has left the chat",
  "username": "yordan"
}
```

---

## ConnectionManager

Tracks all active WebSocket connections in memory:

```python
class ConnectionManager:
    active_connections: dict  # { uuid: websocket }

    connect()      # accept + assign UUID + send join message
    disconnect()   # remove from active connections
    send_message() # send to one connection
    broadcast()    # send to all connections, sets isMe flag
```

Each connection gets a UUID so they can be individually tracked and removed on disconnect.

## Setup

### Prerequisites
- Python 3.10+

### Installation

```bash
# Clone the repo
git clone https://github.com/yourname/chat-app.git
cd chat-app

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Running

```bash
uvicorn database:app --reload
```

Then connect via WebSocket at:
```
ws://localhost:8000/ws/{your_user_id}
```

And use the REST API at:
```
http://localhost:8000/docs  ← Swagger UI auto-generated by FastAPI
```
